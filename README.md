# xBuilt Technologies

ReactJS Website for xBuilt Technologies — A business site showcasing services like Website Design, CRM Pipeline Development, and Video Editing.

## About the Project

xBuilt Technologies is a service-focused website offering:

* Website Design & Development
* CRM Pipeline Development
* Video Editing Services

This site serves as both a client-facing platform and a portfolio piece to demonstrate professional frontend skills in React. It highlights real-world application of React concepts, component-based design, and responsive layouts.

## Features

- Responsive Design
- Clean UI with modern components
- Multiple service pages
- Easy customization for client needs

## Technologies Used

This project was built with the following tools and technologies:

* React.js + Vercel (JS Library and framework)
* JS(ES6+), CSS, HTML (Structure)
* ThreeJS, ThreeFiber (3D objects)
* NodeJS (Ecosystem through npm)
